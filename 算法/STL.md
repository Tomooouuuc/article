

| 容器                             | 名称                                       |
| -------------------------------- | ------------------------------------------ |
| vector                           | 动态数组                                   |
| deque                            | 双端队列                                   |
| list                             | 双向链表                                   |
| forward_list                     | 单向链表                                   |
| array                            | 静态数组                                   |
| set/multiset                     |                                            |
| map/multimap                     |                                            |
| unordered_set/unordered_multiset |                                            |
| unordered_map/unordered_multimap |                                            |
| stack                            | 底层默认deque，（可选 `vector` 或 `list`） |
| queue                            | 底层默认deque                              |
| priority_queue                   | 优先队列。底层默认vector                   |

## 通用操作

| 操作函数  | 用途                       | 时间复杂度 |
| --------- | -------------------------- | ---------- |
| `begin()` | 返回指向首元素的迭代器     | O(1)       |
| `end()`   | 返回指向末尾后位置的迭代器 | O(1)       |
| `size()`  | 返回当前元素数量           | O(1)       |
| `empty()` | 判断容器是否为空           | O(1)       |
| `clear()` | 清空所有元素               | O(n)       |

## 顺序容器操作

#### vector

| 操作函数        | 用途                             | 时间复杂度 |
| --------------- | -------------------------------- | ---------- |
| `push_back(x)`  | 尾部添加元素                     | 摊销 O(1)  |
| `pop_back()`    | 删除尾部元素                     | O(1)       |
| `insert(it, x)` | 在迭代器`it`前插入元素           | O(n)       |
| `erase(it)`     | 删除迭代器`it`指向的元素         | O(n)       |
| `operator[](i)` | 随机访问第`i`个元素              | O(1)       |
| `at(i)`         | 随机访问并检查边界               | O(1)       |
| `resize(n)`     | 调整容器大小（扩展时填充默认值） | O(n)       |
| `reserve(n)`    | 预分配内存（提升性能）           | -          |

#### deque

| 操作函数        | 用途         | 时间复杂度 |
| --------------- | ------------ | ---------- |
| `push_back(x)`  | 尾部添加元素 | O(1)       |
| `push_front(x)` | 头部添加元素 | O(1)       |
| `pop_back()`    | 删除尾部元素 | O(1)       |
| `pop_front()`   | 删除头部元素 | O(1)       |
| `operator[](i)` | 随机访问     | O(1)       |

#### list/forward_list

| 操作函数                               | 用途                                   | 时间复杂度   |
| -------------------------------------- | -------------------------------------- | ------------ |
| `push_back(x)`                         | 尾部添加（`forward_list`无）           | O(1)         |
| `push_front(x)`                        | 头部添加                               | O(1)         |
| `insert_after(it, x)`                  | 在`it`后插入（`forward_list`特有）     | O(1)         |
| `erase_after(it)`                      | 删除`it`后的元素（`forward_list`特有） | O(1)         |
| `splice_after(it, other, first, last)` | 高效合并链表片段（不拷贝元素）         | O(1) 或 O(n) |

#### array

| 操作函数        | 用途                  | 时间复杂度 |
| --------------- | --------------------- | ---------- |
| `operator[](i)` | 随机访问              | O(1)       |
| `fill(x)`       | 所有元素填充为`x`     | O(n)       |
| `swap(arr)`     | 交换两个`array`的内容 | O(n)       |

## 关联容器操作：**`set`, `map`, `multiset`, `multimap`**

#### 共用操作

| 操作函数           | 用途                                     | 时间复杂度 |
| ------------------ | ---------------------------------------- | ---------- |
| `insert(x)`        | 插入元素/键值对                          | O(log n)   |
| `erase(key)`       | 删除指定键的元素                         | O(log n)   |
| `find(key)`        | 查找键是否存在                           | O(log n)   |
| `count(key)`       | 返回键对应的元素数量（`set`总是 0 或 1） | O(log n)   |
| `lower_bound(key)` | 返回第一个不小于`key`的迭代器            | O(log n)   |
| `upper_bound(key)` | 返回第一个大于`key`的迭代器              | O(log n    |

#### map

| 操作函数          | 用途                           | 时间复杂度 |
| ----------------- | ------------------------------ | ---------- |
| `operator[](key)` | 访问或插入键（若不存在则创建） | O(log n)   |

## 无序关联容器操作（`unordered_set`, `unordered_map`, `unordered_multiset`, `unordered_multimap`）

| 操作函数     | 用途                 | 时间复杂度 |
| ------------ | -------------------- | ---------- |
| `insert(x)`  | 插入元素             | O(1)       |
| `erase(key)` | 删除指定键的元素     | O(1)       |
| `find(key)`  | 查找键是否存在       | O(1)       |
| `count(key)` | 返回键对应的元素数量 | O(1)       |

### 容器适配器操作

#### stack

| 操作函数  | 用途         | 时间复杂度 |
| --------- | ------------ | ---------- |
| `push(x)` | 元素压栈     | O(1)       |
| `pop()`   | 弹出栈顶元素 | O(1)       |
| `top()`   | 访问栈顶元素 | O(1)       |

#### queue

| 操作函数  | 用途         | 时间复杂度 |
| --------- | ------------ | ---------- |
| `push(x)` | 元素入队     | O(1)       |
| `pop()`   | 队首元素出队 | O(1)       |
| `front()` | 访问队首元素 | O(1)       |
| `back()`  | 访问队尾元素 | O(1)       |

#### priority_queue

| 操作函数  | 用途             | 时间复杂度 |
| --------- | ---------------- | ---------- |
| `push(x)` | 插入元素并调整堆 | O(log n)   |
| `pop()`   | 删除堆顶元素     | O(log n)   |
| `top()`   | 访问堆顶元素     | O(1)       |

容器适配器需要使用底层容器的迭代器
